## Building

**[CommuteCast](https://github.com/sam666-deb/CommuteCast)** — a commute companion that merges live Melbourne PTV transit data with real-time weather, so you know exactly when to leave the house. React · Node/Express · PostgreSQL. [Try it live →](https://commute-cast-six.vercel.app)
